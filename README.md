# 电力交易员中级工 · 刷题

一个跑在 iPhone 上的离线刷题网页 App，题目来自《理论题目复习参考-电力交易员中级工.xlsx》，共 **790 题**（单选 350 / 多选 200 / 判断 240）。不需要上架 App Store，不需要开发者账号，添加到主屏幕后和普通 App 一样使用。

---

## 一、先装到手机上（选一种）

> ⚠️ 必须用 **Safari 浏览器**打开，微信内置浏览器、夸克、UC 都不支持"添加到主屏幕"。
>
> ⚠️ **不要用 `*.workers.dev` 或 `*.pages.dev` 的默认域名**——这两个域名在国内被 DNS 污染 / 连接重置，会出现"昨天能开今天打不开"。用下面两种方式。

### 方式 A：GitHub Pages（推荐，免费，国内多数网络可访问）

1. 注册 https://github.com/signup （邮箱 + 密码，需要过一下验证）。
2. 右上角 **+** → **New repository**，名字填 `shuati`，选 **Public** → **Create repository**。
3. 在空仓库页面点 **uploading an existing file**，把本文件夹里的**全部文件和文件夹**（`index.html`、`css`、`js`、`icons`、`manifest.json`、`sw.js`）拖进去 → **Commit changes**。
   - 拖文件夹时目录结构会保留，`index.html` 必须在最外层。
4. 仓库 **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch** → Branch 选 `main`、目录 `/ (root)` → **Save**。
5. 等 1–2 分钟刷新本页，顶部会出现 `https://你的用户名.github.io/shuati/` 。
6. iPhone 的 Safari 打开这个网址 → 底部 **分享** → **添加到主屏幕**。

### 方式 B：腾讯云 EdgeOne Pages（国内最稳，需要实名）

1. 打开 https://edgeone.ai ，用微信/QQ 注册并完成实名（个人免费）。
2. 控制台 → **Pages** → 创建项目 → 选择 **直接上传**。
3. 把本文件夹拖进去 → 部署，得到一个 `*.edgeone.app` 的网址。
4. iPhone Safari 打开 → 分享 → 添加到主屏幕。

### 方式 C：只在自己的电脑上先试用（不用注册任何账号）

1. 双击 `本地预览.bat`（需要电脑装了 Python；没装的话用微软商店装一个）。
2. 窗口里会显示「手机访问: http://192.168.x.x:8000」。
3. iPhone 连**同一个 Wi-Fi**，Safari 打开这个地址即可。
4. 缺点是电脑关机就打不开，只适合先试试手感。

> 三种方式第一次打开都需要联网（约 330 KB），之后**完全离线**，飞行模式也能刷。

## 二、功能

| 功能 | 说明 |
|---|---|
| 顺序练习 | 按题库原顺序 1–790 逐题过 |
| 随机练习 | 打乱顺序，避免背题序 |
| 专项练习 | 单选 / 多选 / 判断 分开练 |
| 模拟考试 | 20 题 20 分钟 / 50 题 45 分钟 / 100 题 90 分钟，随机抽题、倒计时、自动评分 |
| 错题本 | 答错自动收录，**连续答对 2 次自动移出**（可改成 1 次或不移出），也能手动删 |
| 收藏 | 题目右上角星标，单独刷 |
| 统计 | 总正确率、各题型掌握度、最近 7 天曲线、模考记录 |
| 断点续答 | 随时退出，回来接着上次那题 |
| 搜索 | 首页右上角放大镜，按关键词找题 |
| 深色模式 / 字号 | 「我的」里可调 |
| 备份 | 「我的 → 导出备份」存成文件；换手机时「导入备份」恢复 |

答题逻辑：单选/判断点一下立刻判对错（可设置答对后自动下一题）；多选勾完点「提交答案」，**必须全部选对才得分**，漏选算错。

## 三、数据说明

- 所有记录（答题、错题、收藏、成绩）**只存在这台手机的浏览器里**，不上传、不联网。
- 删除主屏幕图标不会删数据；但**清除 Safari 数据 / 卸载重装**会清空。
- 建议每隔一段时间点「我的 → 导出备份」存一份到 iCloud 或微信收藏。
- 换手机：旧手机导出 → 把 `.json` 文件发到新手机 → 新手机先装好 App → 「导入备份」选这个文件。

## 四、题库有更新怎么办

题库源文件是 Excel。更新流程：

1. 改好 Excel（保持原结构：A 列题干、B 列 `参考答案：X`、C–G 列选项）。
2. 运行 `python build_questions.py`（脚本在上一级目录），会重新生成 `js/questions.js`。
3. 重新上传网站文件。
4. **重要**：把 `sw.js` 第一行的 `var CACHE = 'dljy-v1';` 改成 `'dljy-v2'`（每次更新都要改），否则手机会一直用旧缓存。
5. 手机上把旧图标删掉，重新「添加到主屏幕」一次，确保拿到新版本。

## 五、常见问题

**Safari 报 `Response served by service worker has redirections`**
- v1 的 bug，已在 v2 的 `sw.js` 修复（根因：托管方把 `/index.html` 308 跳到 `/`，缓存里存了跳转响应，Safari 拒绝渲染）。
- 更新部署后如果第一次打开还报这个错，说明旧的 Service Worker 还没被替换：**关掉 Safari 再打开一次**，或刷新两三次即可。
- 仍然不行就清除该站点数据：设置 → Safari → 高级 → 网站数据 → 找到该网址删除。

**打开是白屏 / 一直转圈**
- 确认用的是 Safari，且网址是 `https://` 开头。
- 本地预览（方式 C）时确认手机和电脑在同一个 Wi-Fi、电脑没关。

**桌面图标是灰色的"网页截图"**
- 说明"添加到主屏幕"时页面还没加载完，删掉重新添加一次。

**更新了网页，手机上还是老的**
- `sw.js` 里的 `CACHE` 版本号没改；改完重新添加图标。

**多选题得分规则**
- 少选、多选、错选都算错，全对才得分（和正式考试一致）。

**没有解析**
- 原题库里就没有解析，App 只显示正确答案。需要的可以自己在 Excel 里加注释。

## 六、文件结构（扁平结构，全部平铺在一个目录）

```
quiz-app/
├── index.html              页面骨架（必须在这个目录最外层）
├── app.css                 样式（浅色/深色）
├── questions.js            790 道题数据（由 Excel 自动生成）
├── app.js                  全部答题逻辑
├── manifest.json           PWA 配置（名称、图标、全屏）
├── sw.js                   Service Worker：离线缓存
├── icon-180.png            主屏幕图标
├── icon-192.png            图标
├── icon-512.png            图标
├── icon-512-maskable.png   图标（Android 自适应）
├── icon-1024.png           图标（备用）
├── 本地预览.bat            本地起服务的小脚本
└── README.md               本文件
```

**上传时把上面这些文件（除 README/ bat 外的 10 个）全选一起拖**，目录里不能有 `css/`、`js/`、`icons/` 这种子文件夹了——之前部署失败就是因为只拖了图标文件夹。传完检查一下文件列表里**必须有 `index.html`**。
